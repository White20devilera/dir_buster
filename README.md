# dir_buster
A powerful web application security tool used for discovering hidden directories and files on a web server. By leveraging custom wordlists, it identifies unlinked content that could lead to sensitive information disclosure.


# Key Features:

Supports custom wordlist paths for flexible brute-forcing.

Real-time HTTP status code reporting (200 OK, 403 Forbidden).

Built-in error handling for network timeouts and protocol validation.
